# Servicio Social - Agentes con Datos Abiertos

Proyecto desarrollado en Python para consultar y analizar datos abiertos mediante agentes.

## Objetivo
Implementar agentes capaces de procesar instrucciones, consultar datos meteorológicos y de calidad del aire, y generar resultados.

## Requisitos
- Python 3.10 o superior

## Ejecución
python main.py
